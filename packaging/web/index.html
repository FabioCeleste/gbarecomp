Use your own dumps. The ROM and BIOS are never uploaded: this tab checks their SHA-1, passes them to the game in memory, and keeps a copy in this browser only if you tick “Remember”. You can also drop both files on the game screen.

Saves stay in this browser (IndexedDB for this site, on this device) and are never uploaded. Private windows, clearing site data or a different domain lose them: export a copy to keep one. X/Z = A/B, arrows = D-pad, C/V = L/R, Enter = Start, right Shift = Select; Shift+P pauses. F1–F9 loads; Shift+F1–F9 saves. Click the game to activate keyboard/gamepad. Sensors and the native overlay are unavailable.

Query params: ?args=--frames%20600%20--no-window replaces the extra runtime arguments; &env=KEY=VALUE,KEY2=VALUE2 sets environment variables; &rom=/dev-assets/game.gba&bios=/dev-assets/gba_bios.bin loads local test files on localhost only (packaging/web/serve.py --dev-assets).
